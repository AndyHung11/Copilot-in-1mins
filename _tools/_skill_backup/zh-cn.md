## 简体中文本地化与用词规范

生成简体中文内容时，必须使用大陆简体中文表达，避免繁体字、港台用词、机器翻译腔和中英混杂 UI 文案。优先使用自然、清晰、面向中国大陆用户的产品文案风格。

### 总体原则

1. 使用简体中文，不得出现用户可见的繁体字。
2. 避免港台地区常见说法，优先使用大陆常用术语。
3. UI 按钮、提示语、状态文案应尽量全中文，不要中英混排，除非产品名、专有名词或品牌名必须保留英文。
4. 技术术语、Microsoft 365 场景、办公软件场景应使用中国大陆常见译法。
5. 表达要自然，避免直译、硬译和不符合中文习惯的句式。
6. 如果同一个词有多个可选译法，默认使用最基础、最通用的大陆简体说法，不做过度区分。
7. 不要修改代码、CSS、字体名称等非用户可见内容中的固定名称，例如 `Microsoft JhengHei`、`微軟正黑體` 这类字体回退设置可保留。
