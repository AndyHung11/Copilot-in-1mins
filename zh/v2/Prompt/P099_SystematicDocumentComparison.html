📑 本週 Prompt（貼進 Copilot Chat – Web 版）

你正在分析兩份文件以進行比較。

任務：系統化地比較這兩份文件。

指示：
1. 首先，辨識文件類型（合約、規格書、報告等）
2. 列出每一份文件中出現的所有章節／標題
3. 針對每一個章節，標註：
   - 僅出現在文件 A
   - 僅出現在文件 B
   - 兩份皆有（比較內容）
4. 標示實質內容的差異（非排版差異）
5. 標記任何矛盾或衝突之處

輸出格式：使用結構化表格，欄位為：| 章節 | 文件 A 狀態 | 文件 B 狀態 | 主要差異 |

限制：
- 僅聚焦於明確存在的文字內容
- 不要從排版推論語意
- 若對某項差異不確定，請註明「需人工複核」
- 依重要性排列發現事項（重大 → 次要）

可在：Copilot Chat – Web 中使用。
📋 Prompt Template (English)
📑 Prompt of the Week (paste into Copilot Chat — Web)

You are analyzing two documents for comparison.

Task: Compare these documents systematically.

Instructions:
1. First, identify the document type (contract, specification, report, etc.)
2. List all sections/headings present in EACH document
3. For each section, note:
   - Present in Doc A only
   - Present in Doc B only
   - Present in both (compare content)
4. Highlight substantive differences (not formatting)
5. Flag any contradictions or conflicts

Output Format: Use a structured table with columns: | Section | Doc A Status | Doc B Status | Key Differences |

Constraints:
- Focus on explicit text content only
- Do not infer meaning from formatting
- If uncertain about a difference, state "Requires human review"
- List findings by importance (critical → minor)

Try it in: Copilot Chat – Web.
💡 三個情境式玩法
1
📎 兩份一起給
同一則對話中同時上傳或貼上兩份文件，它才有辦法逐節對照；分兩次給容易只比到後面那份。
2
⚖️ 指定你在意的重點
補一句「特別注意付款條件、責任範圍與終止條款」，重要性排序會更貼近你的實務判斷。
3
🔍 「需人工複核」要當真
那是它明確表示無法判斷的地方，通常也正是風險最高的條文，務必自己看過。
