本 期 PROMPT
📊 數據簡報大改造
Data Slide Makeover
✨ 文字換圖表 → 一頁一重點 → So-What 洞察 → 品牌配色一致 📊
主管的眼神從第一張數據表就開始渙散——密密麻麻的數字、看不出重點的表格，講到第五頁大家已經在滑手機。你明明花了一整晚整理數據，卻沒人記得你到底想說什麼。

這個 Prompt 直接把整份簡報丟給 Copilot 重新設計：能換圖表的文字就換成圖表，每張數據挑出最適合的呈現方式；再幫每個洞察補一句「所以呢？」，讓數字有意義而不只是好看。

複雜的頁面會被拆成一頁一訊息，前面加上主管摘要頁，整份簡報配色與風格統一。你要的不是更多數據，是讓人一眼就記住重點——這正是它的拿手戲。
  📋 提示詞範本（繁體中文版）
📊 本週 Prompt（貼進 PowerPoint 裡的 Copilot）

把這份數據量龐大的簡報改造到影響力最大化：1）盡可能把文字換成視覺化圖像，2）為每組數據建議最合適的圖表類型，3）加強視覺層次與重點強調，4）為每個洞察寫一句「所以呢？」的結論，5）簡化複雜投影片（每頁只留一個訊息），6）加入主管摘要投影片，7）確保整份簡報配色一致、符合品牌風格。以清晰易懂與令人印象深刻為優先。

可在：PowerPoint 中使用。
  📋 Prompt Template (English)
📊 Prompt of the Week (paste into Copilot in PowerPoint)

Transform this data-heavy presentation for maximum impact: 1) Replace text with visuals where possible, 2) Suggest best chart types for each dataset, 3) Add visual hierarchy and emphasis, 4) Create 'so what' statements for each insight, 5) Simplify complex slides (one message per slide), 6) Add executive summary slides, 7) Ensure color consistency and brand alignment. Prioritize clarity and memorability.

Try it in: PowerPoint.
💡 使用小撇步
1. 🖇️ 先貼上或上傳整份簡報 — 再貼這段 Prompt，Copilot 才能看到完整內容改造。
2. 🎯 想聚焦特定章節 — 可先說「只改造第 3–8 頁」再貼 Prompt。
3. 🔁 改完務必覆核 — 數據來源與數字正確性仍需要你自己確認。
