🔖 工程圖設備標籤辨識
Engineering Image Tag Inspection
✨ 辨識 XXX-AAAA-0000 類標籤 → 標出位置與方向 → 低信心一律不報 🔖
P&ID 圖面攤在桌上，你要把上面的設備標籤一個一個抄進清單。

抄到第四十個的時候，你開始懷疑剛才那個到底是 PT-1042-A 還是 PT-1O42-A。圖面掃描時有點糊，而且有幾個標籤是直的——你得把頭歪過去看。再抄二十個，你已經不太確定自己有沒有跳過哪一區。

這種工作的風險不在於慢，而在於錯得很安靜。抄錯一個字元，清單看起來一樣完整，問題要等到採購、盤點或現場對照時才會爆出來。

這個 Prompt 讓 Copilot 幫你讀圖，但重點不在於它讀得多，而在於它拒絕讀什麼：

它只回報高信心的標籤，明文禁止猜測、禁止把只看得到一半的標籤補完、禁止嘗試讀取模糊或被遮擋的文字。旋轉的文字只有在「人眼也能清楚辨認」的前提下才納入。低信心的項目連列都不列——因為在這種場景下，一個看起來像答案的錯答案，比誠實的「看不清楚」危險得多。

輸出是一張表：標籤文字、位置（如左上）、方向、信心等級（HIGH／MEDIUM）。如果整張圖都讀不出可靠的標籤，它會直接回一句：這張圖可能需要更高解析度或人工檢查。

拿它當第一道快篩——先把看得清楚的抄完，剩下讀不出的那幾個，正好就是你該親自拿放大鏡看的地方。
  📋 提示詞範本（繁體中文版）
🔖 本週 Prompt（先上傳圖面或照片，再貼上）

你正在協助對一張工程圖進行視覺檢查。

任務：以視覺方式辨識圖中所有清楚可讀的標籤。

要尋找的樣式：符合下列格式的標籤：
- XXX-AAAA-0000（數字－字母－數字）
- AA-000-BBB（字母－數字－字母）
- 或其他類似的英數混合設備標籤

準則：
- 標籤可能以水平或垂直方式出現
- 旋轉的文字，僅在人眼可清楚辨認時才納入考量
- 只回報你能以高信心看見的標籤
- 不要猜測或推論只有部分可見的標籤
- 不要嘗試讀取模糊或被遮擋的文字

輸出格式（純文字表格）：| 標籤文字 | 位置（例如左上） | 方向 | 信心程度 |

信心等級：
- HIGH：清楚可讀，沒有歧義
- MEDIUM：可讀，但部分字元不清楚
-（不要回報 LOW 信心的項目）

若沒有任何標籤清楚可見，請回覆：「No confidently readable tags detected. The image may contain tags that require higher resolution or human inspection.」

可在：Copilot Chat – Web 中使用。
  📋 Prompt Template (English)
🔖 Prompt of the Week (upload the drawing or photo first, then paste)

You are assisting with visual inspection of an engineering image.

Task: Visually identify any clearly readable tags in the image.

Pattern to look for: Tags following format like:
- XXX-AAAA-0000 (digits-letters-digits)
- AA-000-BBB (letters-digits-letters)
- Or similar alphanumeric equipment tags

Guidelines:
- Tags may appear horizontally or vertically
- Consider rotated text if clearly legible to a human reader
- Only report tags you can see with HIGH confidence
- Do NOT guess or infer partially visible tags
- Do NOT attempt to read blurry or obscured text

Output Format (plain text table): | Tag Text | Location (e.g., top-left) | Orientation | Confidence |

Confidence levels:
- HIGH: Clearly readable, no ambiguity
- MEDIUM: Readable but some characters unclear
- (Do not report LOW confidence items)

If no tags are clearly visible, state: "No confidently readable tags detected. The image may contain tags that require higher resolution or human inspection."

Try it in: Copilot Chat – Web.
💡 使用小撇步
1. 📷 解析度決定一切 — 掃描或拍照時把圖面放大、對焦拍清楚，讀出來的比例會差很多。整張大圖一次丟進去，不如分區拍幾張清晰的。
2. 🧭 補上你的標籤規則 — 若貴公司有固定編碼規則（例如「前兩碼一定是區域代號」），在 Prompt 後面補一句，可以幫它排除誤判。
3. ✋ 它讀不出來的才是重點 — 回覆裡沒出現的標籤、或標為 MEDIUM 的，正是你該親自核對的清單。務必當作初篩而非定稿，正式用途仍需人工複核。
