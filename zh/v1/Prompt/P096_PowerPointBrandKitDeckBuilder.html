🍭 品牌套件簡報產生器
PowerPoint Brand Kit Deck Builder
✨ 上傳品牌素材 → 打造專屬套件 → 一句話生成品牌簡報 🎁
每次做簡報前，你是不是都要重新翻一次品牌規範 PDF，再一個個把顏色、字型、Logo 貼回投影片？改到一半發現用錯色號，整份重做。

Copilot Brand Kit 讓你把這些素材一次上傳、打包成一個「套件」：範本、字型、Logo、色票、圖片，甚至品牌語氣通通丟進去；如果你已經有品牌規範 PDF，直接上傳，幾秒鐘就能建好套件並分享給團隊。除了自建套件，還內建 Microsoft 官方品牌與 Zava 示範套件可以直接玩。

之後不管是在 Copilot Create 選套件生成，還是直接在 PowerPoint 裡按 Copilot 圖示、點「+」選品牌，打一句「根據這份大綱做一份簡報」，出來的投影片就自動套上你的品牌色彩與風格——不用再手動一頁一頁校正。

甜蜜、辛香，再加一份有品牌感的 PowerPoint

要做有品牌風格的 PowerPoint 簡報嗎？Copilot Brand Kit 功能不只可愛，還很實用。

從 Copilot 的「建立」> 更多… > 品牌套件 開始。

把你的品牌素材——範本、字型、Logo、色票、圖片、語氣——通通上傳，打造你自己的套件。如果你已經有一份品牌規範 PDF，直接上傳，幾秒鐘就能做好一個可用的套件，還能分享給其他人。系統也內建了官方 Microsoft 品牌套件與 Zava 套件可以試用。

你可以在 Copilot Create 裡選套件使用，或直接飛到 PowerPoint，點選 Copilot 圖示，在提示框裡按下「+」號 > 選擇品牌 > 挑你要用的套件。接著打一句像是「根據這份大綱做一份簡報」的提示。

於是，PowerPoint 又一次拯救了你的一天。🍭

可在：Copilot Create 或 PowerPoint 中使用。

Sugar, spice, and a nice branded PowerPoint

Creating branded PowerPoint decks? Copilot Brand Kit features are not just cute, they're powerful too.

Start in Create in Copilot > More… > Brand kits.

Create your own kit by uploading your brand ingredients like templates, fonts, logos, colors, images, voice. If you already have brand guidelines in a PDF, upload that and have something ready to use in seconds and share your kits with others. There's also official Microsoft brand and Zava kits.

Use kits in Copilot Create or fly over to PowerPoint and select the Copilot icon, in the prompt box, smash that + sign > select brand, and choose the kit you want to use. Prompt something like "create a deck from this [insert outline]".

And so once again the day is saved, thanks to PowerPoint. 🍭

Try it in: Copilot Create or PowerPoint.
