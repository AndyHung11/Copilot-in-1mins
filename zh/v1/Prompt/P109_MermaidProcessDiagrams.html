本 期 PROMPT
🔀 用 Mermaid 把流程畫成圖
Mermaid Process Diagrams
🔀 用 Mermaid 文字語法 → 一句話產出流程圖／時程圖 → 看得見、分享得出去 → 括號出錯也有解法
每次要講清楚一個流程，你都得打開簡報工具，一格一格拉方塊、接箭頭——明明內容早就寫在文件裡，卻還得再畫一遍。

更麻煩的是，流程只存在腦袋和幾份文件中，新人看不懂、跨團隊溝通也容易各說各話。

Mermaid 是用純文字描述流程的語言。這組 Prompt 請 Copilot 直接用 Mermaid 畫出流程圖或專案時程，你還能附上自己的檔案當背景資料。偶爾 Copilot 會在圖碼裡塞進括號 ( )，Mermaid 不認得，只要選擇「在 Pages 中編輯」、檢視程式碼，把括號刪掉就能修好。

💡 使用小撇步
🧜 先認識 Mermaid Mermaid 是用純文字描述流程的語法，Copilot 能把文字轉成看得見、可分享的圖。
📎 附上自己的檔案 把流程文件或 SOP 附在 Prompt 後面，Copilot 才會依實際內容畫圖，而不只是通用流程。
🛠️ 括號出錯時這樣修 Copilot 有時會在圖碼裡插入 ( )，Mermaid 無法處理；選擇「在 Pages 中編輯」，檢視程式碼並刪掉括號。
