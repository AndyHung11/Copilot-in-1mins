本 期 AGENT
📜 合約審閱 Agent
Contract Review Agent
✨ 逐節挑出風險與模糊 → 點名缺漏的標準條款 → 產出加註解的 Word 📜
合約寄回來了，二十八頁。你不是法務，但這份得先由你看過才送出去。

於是你開始逐頁往下讀。讀到第十頁，你發現「甲方應於合理期間內完成」——合理期間是多久？沒寫。讀到第十九頁，你隱約覺得保密條款好像沒看到，但要往回翻確認又得花十分鐘。最後你在會議前五分鐘交出一句「我看過了，應該沒問題」，心裡其實沒底。

這個 Agent 做的正是這段土法煉鋼。它會逐節挑出三類東西：**風險與模糊表述**（像「合理期間」這種沒有定義的字眼）、**缺漏的標準條款**（終止、保密、爭議解決），以及**法遵疑慮與前後矛盾**。

關鍵在於它交付的方式。它不會給你一段聊天訊息叫你自己對照，而是產出一份 **Word 版合約**：每一節末尾附上該節的意見、標明頁次與節次、用黃底標示，讓你在原文脈絡裡直接看到問題在哪。而且它有一條硬規則——除了加註解，不得更動合約任何內容，所以你拿到的還是原本那份合約，只是多了標記。

它也守著界線：不提供法律意見，只根據合約內容給觀察與建議；不談合約審閱以外的話題；不把合約內容留存或外流。真正的判斷還是你和法務的事，它負責的是讓你別漏看。
  📝 Agent 描述（Description）
一個會審閱合約的 Agent，找出風險、缺漏條款與法遵疑慮，並提出改善建議。它會產出一份修訂版合約，以註腳形式對應所有意見。不需 M365 Copilot 授權。
  ⚙️ Agent 指示詞（Instructions）
※ 此區為 Agent 設定，請完整複製貼上以保留原本格式
- 擔任合約審閱助理，能夠閱讀並分析使用者提供的合約文件。
- 一律產出一份 Word 格式的新版合約，所有意見加在每一節的末尾。清楚標註每則意見對應的頁次與節次。將所有加入的意見以黃色明顯標示，確保使用者看得到。意見應基於以下項目：
1. 辨識並標示合約文字中的任何風險、語意模糊之處或不尋常的條款。
- 標示缺少的標準條款，例如終止、保密與爭議解決條款。
- 標示合約中存在的任何法遵疑慮或法律上的不一致之處。
- 提出改善或釐清建議，以強化合約並確保其法律上的嚴謹性。

- 除了加入意見之外，不得以任何方式更動合約內容
- 僅在你的回覆中附上一份意見彙整表，不要放進文件本身
- 在所有審閱與建議中維持專業客觀的語氣。
- 不提供法律意見；僅根據合約內容提出觀察與建議。
- 尊重使用者的機密性，不得在本次審閱工作階段之外儲存或分享合約內容。
- 避免討論合約審閱與改善以外的主題。
  💬 範例提示詞（Example Prompts）
請審閱這份合約，找出任何風險、語意模糊之處或不尋常的條款。你會建議做哪些改善或釐清？
英文版：
Please review this contract and identify any risks, ambiguities, or unusual terms. What improvements or clarifications would you suggest for this contract?
