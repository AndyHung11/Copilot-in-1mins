📑 Systematic Document Comparison
✨ Identify the doc type → map every section → flag conflicts → rank by severity 📑
The client sends the revised contract back with one line of context: “minor adjustments.” You open both files side by side and start scrolling.

By page fourteen you've forgotten whether the payment terms on page six actually changed. Worse, some sections have vanished and others are new, so just confirming which version contains a given clause means flipping back and forth twice. And the genuinely dangerous difference — version A says 30 days, version B says 45 — is exactly the one that slips past tired eyes.

This prompt turns comparison into a fixed procedure: identify the document type, list every section in each document, mark each section's presence status, look only at substantive text differences (never formatting), then call out contradictions separately and rank everything from critical conflicts down to minor variations. Where it isn't sure, it says “Requires human review” rather than guessing.
  📋 Prompt Template (English)
📑 Prompt of the Week (paste into Copilot Chat — Web)

You are analyzing two documents for comparison.

Task: Compare these documents systematically.

Instructions:
1. First, identify the document type (contract, specification, report, etc.)
2. List all sections/headings present in EACH document
3. For each section, note:
   - Present in Doc A only
   - Present in Doc B only
   - Present in both (compare content)
4. Highlight substantive differences (not formatting)
5. Flag any contradictions or conflicts

Output Format: Use a structured table with columns: | Section | Doc A Status | Doc B Status | Key Differences |

Constraints:
- Focus on explicit text content only
- Do not infer meaning from formatting
- If uncertain about a difference, state "Requires human review"
- List findings by importance (critical → minor)

📑 本週 Prompt（貼進 Copilot Chat – Web 版）

你正在分析兩份文件以進行比較。

任務：系統化地比較這兩份文件。

指示：
1. 首先，辨識文件類型（合約、規格書、報告等）
2. 列出每一份文件中出現的所有章節／標題
3. 針對每一個章節，標註：
   - 僅出現在文件 A
   - 僅出現在文件 B
   - 兩份皆有（比較內容）
4. 標示實質內容的差異（非排版差異）
5. 標記任何矛盾或衝突之處

輸出格式：使用結構化表格，欄位為：| 章節 | 文件 A 狀態 | 文件 B 狀態 | 主要差異 |

限制：
- 僅聚焦於明確存在的文字內容
- 不要從排版推論語意
- 若對某項差異不確定，請註明「需人工複核」
- 依重要性排列發現事項（重大 → 次要）

可在：Copilot Chat – Web 中使用。
💡 Usage Tips
1. 📎 Give it both at once — Upload or paste both documents in the same conversation so it can map section against section; feeding them separately often means only the second one gets analyzed properly.
2. ⚖️ Name what you care about — Add “pay special attention to payment terms, liability scope, and termination clauses” and the importance ranking will match your real-world judgement.
3. 🔍 Take “Requires human review” seriously — That's it explicitly saying it can't call this one, and those are usually the highest-risk clauses. Read them yourself.
