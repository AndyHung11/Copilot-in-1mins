THIS ISSUE · PROMPT
🔖 Engineering Image Tag Inspection
✨ Finds tags like XXX-AAAA-0000 → notes position and orientation → low-confidence reads never reported 🔖
The P&ID is spread out on your desk and you're transcribing equipment tags into a list, one by one.

Around number forty you start to wonder whether that last one was PT-1042-A or PT-1O42-A. The scan is slightly soft, and a few tags run vertically — you have to tilt your head. Twenty more and you're no longer certain you didn't skip a section.

The risk in this work isn't that it's slow. It's that it fails silently. Get one character wrong and the list still looks complete; the problem only surfaces at procurement, during inventory, or out on site.

This prompt puts Copilot on the drawing — but what matters isn't how much it reads. It's what it refuses to read:

It reports only high-confidence tags. Guessing is forbidden. Completing partially visible tags is forbidden. Attempting blurry or obscured text is forbidden. Rotated text counts only if a human reader could clearly make it out. Low-confidence items don't even get listed — because in this context a wrong answer that looks like an answer is far more dangerous than an honest “can't read it.”

Output is a table: tag text, location (e.g. top-left), orientation, confidence (HIGH/MEDIUM). If nothing on the image is reliably legible, it returns one line saying the image may need higher resolution or human inspection.

Use it as a first pass: let it clear the legible tags, and the handful it couldn't read are precisely the ones that deserve your magnifying glass.
  📋 Prompt Template (English)
🔖 Prompt of the Week (upload the drawing or photo first, then paste)

You are assisting with visual inspection of an engineering image.

Task: Visually identify any clearly readable tags in the image.

Pattern to look for: Tags following format like:
- XXX-AAAA-0000 (digits-letters-digits)
- AA-000-BBB (letters-digits-letters)
- Or similar alphanumeric equipment tags

Guidelines:
- Tags may appear horizontally or vertically
- Consider rotated text if clearly legible to a human reader
- Only report tags you can see with HIGH confidence
- Do NOT guess or infer partially visible tags
- Do NOT attempt to read blurry or obscured text

Output Format (plain text table): | Tag Text | Location (e.g., top-left) | Orientation | Confidence |

Confidence levels:
- HIGH: Clearly readable, no ambiguity
- MEDIUM: Readable but some characters unclear
- (Do not report LOW confidence items)

If no tags are clearly visible, state: "No confidently readable tags detected. The image may contain tags that require higher resolution or human inspection."

💡 Usage Tips
1. 📷 Resolution decides everything — Zoom in and focus when you scan or photograph; the hit rate changes dramatically. Several sharp section shots beat one wide shot of the whole drawing.
2. 🧭 Add your own tag convention — If your organization has a fixed coding scheme (“the first two characters are always the area code”), append that to the prompt to help it rule out false reads.
3. ✋ What it can't read is the point — Tags missing from the output, or marked MEDIUM, are exactly your manual check list. Treat this as a first pass, not a final answer — production use still needs human verification.
