# Copilot in PowerPoint 自訂技能範例

搭配「Copilot 一分鐘小教室」電子報 #23（Copilot in PowerPoint 技能功能）附上的兩個現成自訂技能範例，下載後可直接使用。

## 如何使用

1. 下載本資料夾（或 `PowerPoint_Skills_Examples.zip`）。
2. 在 Copilot in PowerPoint 的提示欄選「+」→「選擇技能」→「管理技能」→「自訂技能」→「建立 OneDrive 資料夾」。
3. 把下列資料夾（含 `SKILL.md`）整個複製到該 OneDrive 技能資料夾中，資料夾名稱需與 `SKILL.md` 內的 `name` 一致。
4. 回到 Copilot 面板重新整理，技能即可在清單或 `@技能名稱` 中使用。

## 收錄技能

| 技能 | 用途 |
|---|---|
| `audience-translator` | 依主管、財務、技術、業務、客戶等不同受眾，一鍵改寫同一份簡報的語氣與重點，不用重做多個版本。 |
| `action-plan-builder` | 從簡報內容自動整理行動項目、負責人、期限與風險，建立一張可追蹤的行動計畫投影片。 |

> 官方自訂技能格式規範：[Copilot in PowerPoint skills](https://support.microsoft.com/zh-tw/powerpoint/copilot/copilot-in-powerpoint-skills)
