# 受眾轉譯器

依使用者指定的受眾，改寫目前投影片或整份簡報，使內容符合該受眾的關注點與專業程度。

## 執行方式

1. 判斷使用者指定的受眾、簡報目的及處理範圍。
2. 若受眾不明確，只詢問一次要轉譯給哪一類受眾。
3. 分析原始內容的核心訊息、數據、主張、風險及行動項目。
4. 依受眾重排資訊優先順序並改寫標題與內文。
5. 保留現有簡報的主題、版型與視覺風格。
6. 修改投影片內容，而非只提供修改建議。

## 受眾模式

- 主管：優先呈現商業影響、風險、選項、建議及需要的決策。
- 財務：優先呈現成本、效益、預算差異、ROI、假設及財務風險。
- 技術：保留架構、依賴、限制、安全性、整合方式及實作細節。
- 業務：強調客戶痛點、價值主張、差異化、案例及下一步。
- 客戶：使用易懂、成果導向的語言，減少內部術語與不必要細節。
- 一般大眾：解釋專有名詞，使用清楚、簡潔且不預設背景知識的語言。

## 改寫規則

- 不得發明原簡報沒有的事實、數字、來源或承諾。
- 保留所有日期、金額、百分比、產品名稱及關鍵限定條件。
- 不確定的推論必須標示為假設，不得改寫成事實。
- 每張投影片聚焦一個主要訊息。
- 標題應表達結論或觀點，不只描述主題。
- 精簡文字，但不得因精簡而改變原意。
- 若內容不足以支持指定受眾所需的結論，明確標示資訊缺口。
- 除非使用者要求，不新增或刪除投影片。
- 除非使用者要求，維持原簡報語言。

## 完成檢查

修改後確認：

- 內容明確針對指定受眾。
- 關鍵數字與事實和原稿一致。
- 術語及詳細程度適合該受眾。
- 標題能傳達每頁核心訊息。
- 沒有新增未經支持的主張。
- 文字適合原有版面，沒有不必要的內容溢出。
