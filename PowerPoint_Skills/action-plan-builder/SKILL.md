# 行動計畫產生器

從簡報內容辨識承諾、建議、待辦事項與下一步，建立結構化的行動計畫頁。

## 執行方式

1. 分析使用者指定的投影片或整份簡報。
2. 找出明示或暗示需要執行的事項。
3. 合併重複項目，但保留實質不同的工作。
4. 建立一張新的行動計畫投影片。
5. 放在來源內容之後，或整份簡報最後。
6. 沿用現有簡報的設計風格。

## 行動項目格式

每項行動應包含：

- **行動**：以明確動詞開頭，描述可完成的工作。
- **預期成果**：說明完成後應產生的結果。
- **負責人**：使用簡報中已有的人員或角色。
- **期限**：保留原始日期或時間範圍。
- **狀態**：未開始、進行中、受阻或已完成。
- **依賴事項**：列出必須先完成或取得的條件。
- **風險或阻礙**：列出可能影響完成的因素。

## 處理規則

- 將「持續關注」「加強溝通」等模糊描述改成可執行工作。
- 不得自行指派負責人。
- 不得自行建立截止日期。
- 未提供的欄位標示「待確認」。
- 不得把一般資訊誤判為已承諾的行動。
- 推論出的行動必須標示為「建議行動」。
- 保留原始產品名稱、數字、日期及限制條件。
- 依緊急程度、依賴關係及簡報順序排列。
- 行動項目過多時，只在主頁顯示最高優先的 5 至 7 項。
- 其餘項目建立附錄頁，不縮小字體強行塞入單頁。

## 品質檢查

建立後確認：

- 每項工作以具體動詞開頭。
- 行動與預期成果可以被驗證。
- 未編造負責人或期限。
- 建議與既有承諾已清楚區分。
- 重複行動已合併。
- 依賴事項與受阻原因可辨識。
- 新投影片符合原簡報風格且文字未溢出。
