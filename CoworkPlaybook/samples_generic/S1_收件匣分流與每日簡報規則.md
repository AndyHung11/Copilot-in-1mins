# 收件匣分流與每日簡報規則

> 把這份規則交給 Cowork，讓它每天用同一套標準幫你整理收件匣、規劃一週、產出晨間簡報。

## 一、四象限分流規則
請把收件匣的每封信歸到下列其中一類：

| 類別 | 判斷標準 | 建議動作 |
|------|----------|----------|
| 🔴 需我親自回覆 | 直接點名我、含問題或需我決策 | 今日內回覆，列入待辦 |
| 🟡 需追蹤 | 我已交辦、等對方回覆或等進度 | 設提醒、記入追蹤清單 |
| 🟢 可授權/轉派 | 他人即可處理 | 轉派並 cc 我 |
| ⚪ 僅供參考 | 公告、電子報、自動通知 | 歸檔，不需動作 |

## 二、緊急度標記
- 從「需我親自回覆」中，挑出最多 3 封「今天非處理不可」的，標為 ⭐ 最優先。
- 判斷依據：客戶或高層寄出、含明確期限（今明兩天）、阻擋他人工作。

## 三、一週規劃原則
- 對照行事曆空檔，把待辦排進本週，每天聚焦 1 個「最重要任務」。
- 會議日不排深度工作；把零碎回覆集中在固定時段處理。

## 四、每日簡報格式（晨間 5 分鐘讀完）
1. **今日焦點**：一句話講今天最重要的事
2. **今日會議**：時間 + 主題 + 我需要準備什麼
3. **必須回覆**：⭐ 清單（含對象與一句話重點）
4. **等待中**：我在等誰回覆
5. **提醒**：今天到期或需決策的事項

## 五、排程執行設定
把這套流程交給排程之後，Cowork 會依下列設定自己執行：

| 項目 | 設定 |
|------|------|
| 執行時間 | 每天早上 **08:30**（改成你實際的上班時間） |
| 執行範圍 | 前一個工作日 17:00 之後到執行當下的新信 |
| 週末 | 不執行；週一早上一併處理週末累積的信 |
| 產出去向 | 晨間簡報寄到**我自己的信箱** |
| 沒有新信時 | 仍寄出簡報，但註明「今日無需處理的新信」 |

> ⚠️ **練習完記得暫停**：這是真的排程，不暫停的話明天早上會真的執行。
> 到「自動化」頁把它設為暫停即可，不必刪除。
