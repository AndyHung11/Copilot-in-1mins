# 信息隔离墙作业规范

版本：2026 年版 ｜ 维护部门：总部合规部
适用：Zava 金融控股及其子公司

---

## 第一条　目的

Zava 证券与Zava 基金管理分别从事证券自营、承销业务与基金管理业务，
两者的业务信息若由同一人同时取得，将构成利益冲突并可能损及基金持有人权益。
为防范此情形，制定本规范。

## 第二条　受规范信息

下列信息**不得由同一人同时取得**：

| 类别 | 内容 |
|---|---|
| A 类 | Zava 基金管理所管理基金的**拟投资标的、投资头寸变动计划、申赎异常**信息 |
| B 类 | Zava 证券的**自营头寸计划、承销项目未公开信息、研究报告发布前内容**信息 |
| C 类 | Zava 基金管理基金的**销售渠道配置、渠道激励条件、渠道别销售预测**信息 |

## 第三条　兼任人员的处理

1. 集团内部分子公司因规模考虑，其合规负责人由关系较近的子公司
   合规负责人**兼任**，此属合规的人事安排，本规范不予禁止。
2. 但兼任人员在**同时涉及第二条 A、B 或 C 类信息的会议、文件或讨论**时，
   应按下列方式之一处理：

   | 方式 | 做法 | 适用时机 |
   |---|---|---|
   | **分场办理** | 将受规范议题**从原会议独立出来**，另行安排场次，出席人仅限该子公司相关人员 | ⭐ 议题本身必须讨论，且兼任人员为该子公司的当然出席人时 |
   | 回避 | 兼任人员在该议题讨论时离席 | 兼任人员非该议题的必要出席人时 |
   | 书面替代 | 以书面意见取代出席 | 议题性质单纯、无须即时讨论时 |

3. **不得**以“兼任人员本人承诺不披露”作为替代处理方式。

## 第四条　排会时的检查

排定跨子公司会议时，召集部门应在发出邀请**之前**完成下列检查：

- [ ] 对照《合规窗口名册.md》确认有无兼任情形
- [ ] 逐项检视议程，标示受本规范规范的议题
- [ ] 受规范议题按第三条选定处理方式
- [ ] 采分场办理的，**两场的出席人名单应分别确认**

## 第五条　记录

采分场办理的，两场会议的纪要应分别制作，不得合并。
分场的原因应在纪要中载明。
