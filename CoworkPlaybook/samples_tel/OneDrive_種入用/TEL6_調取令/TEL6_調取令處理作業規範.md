# 調取令處理作業規範（摘錄）

> 文件管理：網路技術處　|　ZVT-REG-P-0355　|　版次 2.4

## 1. 收到調取令後的處理順序

```
步驟 1  確認令狀形式要件（核發機關、案號、受調取門號、調取期間、簽章）
步驟 2  **逐類紀錄**比對調取期間與該類紀錄之法定留存期限
步驟 3  就各類紀錄分別判定：全段提供／部分提供／無法提供
步驟 4  於回覆期限內函復，無法提供者敘明法律依據
```

⚠️ **第 2 步是逐類，不是整批。** 不同類別的紀錄留存期限不同，
　　同一張令狀很可能一部分可提供、一部分已逾留存期限。

## 2. 各類紀錄之法定留存期限

| 紀錄類別 | 留存期限 |
|---|---|
| 通信紀錄（通聯） | 12個月 |
| 上網歷程 | 6個月 |
| 帳務資料 | 60個月 |
| 基地台位置紀錄 | 6個月 |

## 3. 判定方式

```
留存起日 = 收文日 − 留存期限

令狀起日 >= 留存起日  →  該類紀錄可全段提供
令狀起日 <  留存起日  →  **部分提供**（自留存起日起），
                          留存起日之前的部分敘明已逾留存期限無法提供
```

⚠️ **不得因為部分無法提供就整張令狀拒絕**，也**不得因為部分可提供就全段提供**
　　（逾留存期限之資料本已刪除，無從提供）。

## 4. 回覆函應載明

1. 來文機關、來文字號、來文日期
2. **逐類紀錄**之處置（可提供期間、無法提供期間及其法律依據）
3. 提供之資料格式與交付方式
4. 承辦人與聯絡方式

## 5. 回覆期限

自收文日起 **7 日**（曆日）內函復。

## 6. 不得為之

- 不得提供令狀所載調取期間以外之資料。
- 不得提供令狀所載受調取門號以外之門號資料。
- 不得因資料不全而逕予拒絕；應就可提供部分先行提供。
- 不得逾越回覆期限而未函復。
