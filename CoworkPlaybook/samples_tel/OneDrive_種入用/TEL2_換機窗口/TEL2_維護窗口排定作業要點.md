# 維護窗口排定作業要點（摘錄）

> 文件管理：網路技術處　|　ZVT-NET-P-0207　|　版次 2.4

## 1. 一個窗口要同時滿足三個條件

| 條件 | 門檻 | 哪裡查 |
|---|---|---|
| 噪音管制 | 住宅區 22:00–07:00 之間，發出噪音之作業不得超過 30 分鐘 | 本要點 |
| 企業專線批次傳輸 | 該時段批次量不得超過 5.0 TB | 〈TEL2_換機窗口評估.xlsx〉的「窗口方案」 |
| 消費用戶影響 | 受影響用戶不得超過 20,000 戶（超過須報處長核定） | 同上 |

⚠️ **三者皆為硬條件，任一不過即不可排定。** 不是加權計分，不能用
「消費用戶特別少」去折抵「企業批次特別多」。

## 2. 為什麼深夜不是答案

直覺會挑消費用戶最少的深夜時段。但電信網路的兩種客戶**尖峰剛好錯開**：

```
消費用戶尖峰   19:00 – 23:00（影音、社群）
企業批次尖峰   00:00 – 05:00（資料同步、備份、結算）
```

深夜消費用戶最少，**正是企業客戶的批次傳輸尖峰**，而且落在噪音管制時段內。
真正可行的窗口通常落在**兩個尖峰之間的縫隙**。

## 3. 噪音管制怎麼算

管制時段內**可以**做準備作業（拉線、架設、設定），**不可以**做會發出噪音的作業
（鑽孔、吊裝、發電機）。因此判定方式是：

```
窗口與管制時段的重疊分鐘數 > 30 分鐘  →  衝突
重疊 <= 30 分鐘                      →  可排定（重疊段只做準備）
```

## 4. 不得為之

- 不得為了避開企業批次而把窗口推進噪音管制時段。
- 不得在未確認三項條件前通知客戶。
- 不得壓縮標準工期以塞進較短的窗口。
