# 调取令处理作业规范（摘录）

> 文件管理：网络技术部　|　ZVT-REG-P-0355　|　版次 2.4

## 1. 收到调取令后的处理顺序

```
步骤 1  确认令状形式要件（核发机关、案号、被调取号码、调取期间、签章）
步骤 2  **逐类记录**比对调取期间与该类记录的法定留存期限
步骤 3  就各类记录分别判定：全段提供／部分提供／无法提供
步骤 4  在回复期限内函复，无法提供的叙明法律依据
```

⚠️ **第 2 步是逐类，不是整批。** 不同类别的记录留存期限不同，
　　同一张令状很可能一部分可提供、一部分已超过留存期限。

## 2. 各类记录的法定留存期限

| 记录类别 | 留存期限 |
|---|---|
| 通信记录（通话） | 12个月 |
| 上网历程 | 6个月 |
| 账务数据 | 60个月 |
| 基站位置记录 | 6个月 |

## 3. 判定方式

```
留存起日 = 收文日 − 留存期限

令状起日 >= 留存起日  →  该类记录可全段提供
令状起日 <  留存起日  →  **部分提供**（自留存起日起），
                          留存起日之前的部分叙明已超过留存期限无法提供
```

⚠️ **不得因为部分无法提供就整张令状拒绝**，也**不得因为部分可提供就全段提供**
　　（超过留存期限的数据本来就已删除，无从提供）。

## 4. 回复函应载明

1. 来文机关、来文字号、来文日期
2. **逐类记录**的处置（可提供期间、无法提供期间及其法律依据）
3. 提供的数据格式与交付方式
4. 承办人与联系方式

## 5. 回复期限

自收文日起 **7 日**（日历日）内函复。

## 6. 不得为之

- 不得提供令状所载调取期间以外的数据。
- 不得提供令状所载被调取号码以外的号码数据。
- 不得因为数据不全就直接拒绝；应就可提供部分先行提供。
- 不得超过回复期限而未函复。
