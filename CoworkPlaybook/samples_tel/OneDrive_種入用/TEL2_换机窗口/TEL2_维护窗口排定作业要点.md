# 维护窗口排定作业要点（摘录）

> 文件管理：网络技术部　|　ZVT-NET-P-0207　|　版次 2.4

## 1. 一个窗口要同时满足三个条件

| 条件 | 门槛 | 在哪儿查 |
|---|---|---|
| 噪音管制 | 住宅区 22:00–07:00 之间，产生噪音的作业不得超过 30 分钟 | 本要点 |
| 企业专线批量传输 | 该时段批量不得超过 5.0 TB | 《TEL2_换机窗口评估.xlsx》的“窗口方案” |
| 消费用户影响 | 受影响用户不得超过 20,000 户（超过须报部门经理核定） | 同上 |

⚠️ **三者都是硬条件，任一不过就不能排定。** 不是加权计分，不能用
“消费用户特别少”去抵“企业批量特别多”。

## 2. 为什么深夜不是答案

直觉会挑消费用户最少的深夜时段。但电信网络的两种客户**高峰刚好错开**：

```
消费用户高峰   19:00 – 23:00（视频、社交）
企业批量高峰   00:00 – 05:00（数据同步、备份、结算）
```

深夜消费用户最少，**正是企业客户的批量传输高峰**，而且落在噪音管制时段内。
真正可行的窗口通常落在**两个高峰之间的缝隙**。

## 3. 噪音管制怎么算

管制时段内**可以**做准备作业（拉线、架设、配置），**不可以**做会产生噪音的作业
（钻孔、吊装、发电机）。所以判定方式是：

```
窗口与管制时段的重叠分钟数 > 30 分钟  →  冲突
重叠 <= 30 分钟                      →  可排定（重叠段只做准备）
```

## 4. 不得为之

- 不得为了避开企业批量而把窗口推进噪音管制时段。
- 不得在没确认三项条件前通知客户。
- 不得压缩标准工期以塞进较短的窗口。
