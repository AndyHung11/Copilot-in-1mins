# 個人資料外洩事件通報作業程序

> 這份 SOP 是事件觸發任務的判斷依據。資安通報信進來時 Cowork 自己讀這份文件，
> 不需要有人先判斷等級與期限再告訴它。

## 一、⚠️ 法定 72 小時的起算點（最關鍵的一條）

> **法定 72 小時自「知悉／發現」時點起算，不是自「事件發生」時點起算。**

資安事件的發生時間與發現時間**經常相差數日**。
通報信中若同時出現兩個時間，**一律取「發現時間」為起算基準**，
並在通報內容中同時載明兩個時間與其落差。

```
法定通報期限 = 發現時間 + 72 小時
剩餘時數     = 法定通報期限 − 現在時間
```

## 二、事件分級

| 等級 | 判定條件 | 通報義務 |
|---|---|---|
| **重大** | 影響筆數 ≥ 10,000 筆，或含金融帳號、身分證字號、通聯紀錄任一 | 主管機關 + 當事人 + 內部高層 |
| **中度** | 影響筆數 1,000～9,999 筆，且不含前述敏感欄位 | 主管機關 + 內部 |
| **輕微** | 影響筆數 < 1,000 筆，且不含前述敏感欄位 | 內部留存，主管機關得免通報 |

> 只要含**通聯紀錄**，無論筆數多寡一律列為**重大**（電信業特別規定）。

## 三、每則通報必須包含

1. 事件發生時間與**發現時間**（兩者都要寫，不可只寫其一）
2. 距法定 72 小時期限**剩餘時數**
3. 外洩資料類型與影響筆數
4. 分級與所依據的條件
5. 已採取的控制措施
6. 對當事人的預計通知方式與時程
7. 尚待釐清事項（未知者寫「調查中」，不得臆測）

## 四、時程里程碑（須排入行事曆）

| 里程碑 | 時點 | 目的 |
|---|---|---|
| T+24h | 發現後 24 小時 | 內部跨部門會議，確認影響範圍 |
| T+48h | 發現後 48 小時 | 通報書初稿完成、法務複核 |
| T+72h | 發現後 72 小時 | **法定通報期限，不可逾期** |

## 五、通報對象

| 對象 | 方式 | 內容 |
|---|---|---|
| 資安長與法務 | Email | 完整事件內容與通報書草稿 |
| 資安應變小組 | Teams 頻道 | 一行摘要 + 剩餘時數 |
| 三個里程碑 | 行事曆 | 各 30 分鐘會議 |

> ⚠️ 對主管機關與當事人的正式通報，**一律先草擬、等法務與資安長核准後才送出**。
