# 机队可靠性方案摘要

> 文件管理：机务工程部 技术服务室　|　ZV-ENG-R-0601　|　版次 3.1

## 1. 主要指标

| 指标 | 定义 | 警戒值 |
|---|---|---|
| 技术性延误率 | 当月因技术原因延误的航班数 ÷ 当月总航班数 | 1.5% |
| 重复故障 | 同一航空器、同一 ATA 章节、30 日内发生 3 次（含）以上 | 达到定义即开案 |

## 2. 比较口径（这一节最常被忽略）

月度对比要有意义，**两个月的机队构成必须一致**。

航空器进厂定检期间完全不在线，航班数挂零，这架飞机当月的延误也跟着消失。
要是这架飞机平时的延误率高于机队平均，**它一缺席，全机队的平均就自动变好**
—— 这跟任何可靠性改善都没关系。

所以比较月度趋势时，应同时给出两组数字：

```
表面数字      两个月各自的全机队延误率
同口径数字    两个月都剔除当期未在线的航空器后重算
```

⚠️ **两组数字方向要是不一致，应以同口径数字为准，并在报告中讲清楚。**
只报表面数字而不披露机队构成变动，等同于误导。

## 3. 重复故障定义的已知局限

现行定义是“同一航空器、同一 ATA 章节、30 日内发生 3 次（含）以上”。这个定义是**以航空器为单位**设计的，
抓得到同一架飞机反复出事，但抓不到下面这些情况：

- 同一批号的件装在不同航空器上，各出一次 —— 件数一样，但三架各一次不满足定义
- 同一故障分散在三个月内，每月一次

发现同一 ATA 章节的故障**跨机号集中在同一件号或批号**时，
应以专项方式提出，不受现行重复故障定义限制。

## 4. 月报应回答的问题

1. 本月指标数字是多少？跟上月比怎么样？
2. **机队构成有没有变动？同口径比较的结果是什么？**
3. 重复故障清单里，有没有跨机号的共同件号或批号？
4. 需要哪个部门采取什么行动？

## 5. 不得为之

- 不得在机队构成变动的月份只给表面数字。
- 不得把没达到重复故障定义的跨机情况直接结案。
- 不得拿单月数字宣告趋势改善。
