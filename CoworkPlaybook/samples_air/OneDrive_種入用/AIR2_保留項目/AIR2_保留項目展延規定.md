# 保留項目展延規定（摘錄）

> 文件管理：機務工程處 技術服務部　|　ZV-ENG-P-0211　|　版次 3.1

## 1. 類別與修復期限

保留項目（Deferred Defect）依最低裝備需求手冊（MEL）分為四類，
修復期限自**開立次日**起算：

| 類別 | 修復期限 | 得否展延 |
|---|---|---|
| A | 依 MEL 各該條目個別規定，無通則 | **不得展延** |
| B | 3 個曆日 | 得展延一次，期間相同 |
| C | 10 個曆日 | 得展延一次，期間相同 |
| D | 120 個曆日 | 得展延一次，期間相同 |

⚠️ **類別的嚴重度與時間壓力是兩回事。** A 類條件最嚴（不得展延、期限最短），
但若料件已在手上，它反而是最不需要擔心的一項。真正會卡住簽派的，是
**料件到不了、而展延額度又已經用掉**的那一項。

## 2. 展延條件

展延須同時符合下列各項，缺一不可：

1. 類別為 B、C 或 D（A 類不得展延）。
2. **本項目尚未展延過。** 展延以一次為限，不得二次展延。
3. 原保留之限制條件（操作限制、維修措施）仍持續有效。
4. 經授權人員簽署並記錄於航空器技術記錄簿。

## 3. 料件時效的判斷

每項保留項目都要同時看兩個日期：

```
修復期限（含展延後）   ←  法規給的時間
料件預計到達日 ETA     ←  現實給的時間
```

**ETA 晚於修復期限**者，即為會造成簽派中斷的項目，須立即啟動下列其一：

- 向其他基地或租賃管道調借料件。
- 申請 AOG 急件運送。
- 若上述皆不可行，須在期限屆至前安排航空器停場，並通知航務處調整班表。

## 4. 不得為之

- 不得以「料件在途」為由自行延後修復期限。
- 不得對已展延過的項目再次展延。
- 不得僅因類別為 D 就不追蹤料件 —— 120 日照樣會到。
