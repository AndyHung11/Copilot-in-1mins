# 保留项目延期规定（摘录）

> 文件管理：机务工程部 技术服务室　|　ZV-ENG-P-0211　|　版次 3.1

## 1. 类别与修复期限

保留项目（Deferred Defect）按最低设备清单（MEL）分为四类，
修复期限自**开立次日**起算：

| 类别 | 修复期限 | 能否延期 |
|---|---|---|
| A | 按 MEL 各该条目单独规定，没有通则 | **不得延期** |
| B | 3 个日历日 | 可延期一次，期限相同 |
| C | 10 个日历日 | 可延期一次，期限相同 |
| D | 120 个日历日 | 可延期一次，期限相同 |

⚠️ **类别的严重程度和时间压力是两码事。** A 类条件最严（不得延期、期限最短），
但要是备件已经到手，它反倒是最不用操心的一项。真正会卡住签派的，是
**备件到不了、延期额度又已经用掉**的那一项。

## 2. 延期条件

延期必须同时满足下列各项，缺一不可：

1. 类别为 B、C 或 D（A 类不得延期）。
2. **本项目还没有延期过。** 延期以一次为限，不得二次延期。
3. 原保留的限制条件（使用限制、维修措施）仍然有效。
4. 经授权人员签署，并记入航空器技术记录本。

## 3. 备件时效怎么判

每项保留项目都要同时看两个日期：

```
修复期限（含延期后）   <-  法规给的时间
备件预计到达日 ETA     <-  现实给的时间
```

**ETA 晚于修复期限**的，就是会造成签派中断的项目，须立刻启动下列之一：

- 从其他基地或租赁渠道调借备件。
- 申请 AOG 加急运送。
- 上述都走不通的，须在期限届满前安排航空器停场，并通知运行控制部调整航班。

## 4. 不得为之

- 不得以“备件在途”为由自行推后修复期限。
- 不得对已经延期过的项目再次延期。
- 不得因为类别是 D 就不跟踪备件 —— 120 天照样会到。
