# 冷鏈貨品作業規範（摘錄）

> 文件管理：機務工程處 技術服務部　|　ZV-CGO-S-0082　|　版次 3.1

## 1. 累計離溫時數

溫控貨品的允收條件不是「全程維持在溫區內」，而是
**整條運送鏈路的累計離溫時數不得超過該批貨的允收上限**。

累計離溫自貨品離開託運人冷藏庫起算，包含：

```
集貨 → 報關 → 機場冷庫等待 → 裝載 → 飛行 → 清關 → 冷鏈卡車接駁 → 受貨人冷庫
```

⚠️ **機務的延誤本身通常不是問題，問題在它會不會讓貨錯過下一段的時間窗。**
一段 4 小時的延誤若未影響接駁，只消耗 4 小時額度；
若因此錯過接駁車的當日收貨截止，額外產生的冷庫等待時數會是前者的數倍。

## 2. 目的地接駁的時間窗

| 項目 | 規定 |
|---|---|
| 冷鏈卡車當日收貨截止 | 18:00（當地時間） |
| 次日最早收貨 | 08:00（當地時間） |
| 錯過截止之冷庫等待 | 以 14 小時計入累計離溫 |

## 3. 評估順序

發生任何可能影響抵達時間的事件時，依序回答三個問題：

1. 這班機載了哪些溫控貨？各批的允收上限與已消耗時數是多少？
2. 延誤後的預計抵達時間，還趕得上當日收貨截止嗎？
3. 若趕不上，加計冷庫等待後的累計離溫，會不會超過允收上限？

**第三題的答案才是真正要通報的內容。** 只回報「航機延誤 N 小時」
而不回答第三題，收貨人無從判斷是否要啟動退運或重新檢驗。

## 4. 通報對象

累計離溫預估超出允收上限時，須同時通知：

- 貨運處控艙（吳佳蓉）—— 評估改派或退運
- 航務處聯管中心（黃志明）—— 評估航班調整
- 受貨人 —— 由貨運處對外聯繫，**機務不得逕行對外通報**

## 5. 不得為之

- 不得只看單段延誤時數而不回推整條鏈路。
- 不得假設「下一班補上就好」—— 須查證次一班的實際間隔。
- 不得由機務直接聯繫受貨人或託運人。
