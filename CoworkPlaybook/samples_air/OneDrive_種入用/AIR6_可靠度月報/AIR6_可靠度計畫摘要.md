# 機隊可靠度計畫摘要

> 文件管理：機務工程處 技術服務部　|　ZV-ENG-R-0601　|　版次 3.1

## 1. 主要指標

| 指標 | 定義 | 警戒值 |
|---|---|---|
| 技術性延誤率 | 當月因技術原因延誤之班次 ÷ 當月總班次 | 1.5% |
| 重複故障 | 同一航機、同一 ATA 章節、30 日內發生 3 次（含）以上 | 達定義即開案 |

## 2. 比較基準（本節最常被忽略）

月比數字要有意義，**兩個月的機隊組成必須相同**。

航空器進廠定檢期間完全不在線，班次掛零，該機當月的延誤也一併消失。
若該機平時的延誤率高於機隊平均，**它一缺席，全機隊的平均就會自動變好**
—— 而這與任何可靠度改善無關。

因此比較月度趨勢時，應同時提供兩組數字：

```
表面數字      兩個月各自的全機隊延誤率
同口徑數字    兩個月都排除當期未在線的航空器後重算
```

⚠️ **兩組數字的方向若不一致，應以同口徑數字為準，並在報告中明確說明。**
只報表面數字而未揭露機隊組成變動，形同誤導。

## 3. 重複故障定義的已知限制

現行定義為「同一航機、同一 ATA 章節、30 日內發生 3 次（含）以上」。這個定義是**以航空器為單位**設計的，
抓得到同一架機反覆出事，但抓不到下列樣態：

- 同一批號的件裝在不同航空器上，各出一次 —— 件數相同，但三架各一次不滿足定義
- 同一故障分散在三個月內，每月一次

發現同一 ATA 章節的故障**跨機尾號集中於同一件號或批號**時，
應以專案方式提出，不受現行重複故障定義限制。

## 4. 月報應回答的問題

1. 本月指標數字是多少？與上月比較如何？
2. **機隊組成有沒有變動？同口徑比較的結果是什麼？**
3. 重複故障清單中，有沒有跨機尾號的共同件號或批號？
4. 需要哪個單位採取什麼行動？

## 5. 不得為之

- 不得在機隊組成變動的月份只提供表面數字。
- 不得把未達重複故障定義的跨機樣態逕行結案。
- 不得以單月數字宣告趨勢改善。
