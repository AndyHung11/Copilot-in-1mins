# 冷链货品作业规范（摘录）

> 文件管理：机务工程部 技术服务室　|　ZV-CGO-S-0082　|　版次 3.1

## 1. 累计脱温时长

温控货品的允收条件不是“全程保持在温区内”，而是
**整条运输链路的累计脱温时长不得超过该批货的允收上限**。

累计脱温从货品离开托运人冷藏库起算，包括：

```
集货 → 报关 → 机场冷库等待 → 装载 → 飞行 → 清关 → 冷链卡车接驳 → 收货人冷库
```

⚠️ **机务的延误本身通常不是问题，问题是它会不会让货赶不上下一段的时间窗。**
一段 4 小时的延误如果没影响接驳，只消耗 4 小时额度；
要是因此错过接驳车的当日收货截止，多出来的冷库等待时长会是前者的好几倍。

## 2. 目的地接驳的时间窗

| 项目 | 规定 |
|---|---|
| 冷链卡车当日收货截止 | 18:00（当地时间） |
| 次日最早收货 | 08:00（当地时间） |
| 错过截止的冷库等待 | 按 14 小时计入累计脱温 |

## 3. 评估顺序

发生任何可能影响到达时间的事件时，按顺序回答三个问题：

1. 这班飞机装了哪些温控货？各批的允收上限和已消耗时长是多少？
2. 延误之后的预计到达时间，还赶得上当日收货截止吗？
3. 要是赶不上，算上冷库等待之后的累计脱温，会不会超过允收上限？

**第三题的答案才是真正要通报的内容。** 只报“航班延误 N 小时”
而不回答第三题，收货人没法判断要不要启动退运或者重新检验。

## 4. 通报对象

累计脱温预计超出允收上限时，须同时通知：

- 货运部舱位控制（吴丽娟）—— 评估改派或退运
- 运行控制中心（黄建军）—— 评估航班调整
- 收货人 —— 由货运部对外联系，**机务不得直接对外通报**

## 5. 不得为之

- 不得只看单段延误时长而不回推整条链路。
- 不得想当然认为“下一班补上就行”—— 要核实次一班的实际间隔。
- 不得由机务直接联系收货人或托运人。
