# 門市營運週報產生器

## 使用時機

使用者提供門市週營運原始數據並要求「營運週報」「店群週報」「戰情週報」時觸發。若使用者只要求單純的數據計算或樞紐分析，不要使用本技能。

## 產出物

一次產生兩份檔案：

1. **HTML 視覺化週報**（`門市營運週報_YYYY_Wxx.html`）：單一檔案、內嵌 CSS、不依賴外部資源，可直接用瀏覽器開啟或轉存 PDF。
2. **Email 版摘要**（`門市營運週報_Email版_YYYY_Wxx.md`）：可直接貼進郵件的純文字／簡易 HTML 摘要，長度控制在螢幕一頁內。

## 計算與判讀規則

- 達成率 = 週銷售額 ÷ 週目標。若原始資料已提供達成率，直接採用，不要重算。
- **店群分級**：達成率 ≥ 105% 為「領先」、95%～105% 為「符合預期」、85%～95% 為「落後」、低於 85% 為「嚴重落後」。
- **健康度指標**：同時檢視客單價、庫存週轉、缺貨次數、客訴件數，任兩項低於全店平均者標示為「需關注」。
- **缺貨警訊**：缺貨次數 10 次以上者，一律列入下週優先處理事項。
- **客訴警訊**：客訴件數 5 件以上者，須於報告中單獨列出並建議追查原因。
- 所有百分比取一位小數，金額使用千分位。

## HTML 週報結構（依序）

1. **標題列**：週別、統計期間、產出日期。
2. **總覽數字卡**：全店合計銷售額、合計來客數、平均客單價、整體達成率（四張卡片橫排）。
3. **店群分級區**：以四個色塊呈現領先／符合預期／落後／嚴重落後，各列出門市名稱與達成率。
4. **門市績效表**：所有欄位完整呈現，達成率欄位以橫條長度視覺化，嚴重落後者整列標色。
5. **需關注門市**：列出被標示「需關注」的門市，逐店說明是哪兩項指標低於平均。
6. **下週優先處理事項**：依影響程度排序，每項註明門市與建議動作。

### HTML 樣式要求

- 使用系統字體堆疊，中文優先 Microsoft JhengHei。
- 主色 `#8A3A62`，領先 `#2E7D5B`、落後 `#B4551B`、嚴重落後 `#A4373A`。
- 卡片與表格使用淺灰邊框與圓角，避免過度裝飾。
- 必須是單一 HTML 檔，CSS 內嵌於 `<style>`，不引用任何外部 CDN 或字型連結。

## Email 版摘要結構

- 主旨建議：`【門市營運週報】YYYY 第 xx 週 — 整體達成率 xx.x%`
- 開頭一句話總結整體達成狀況。
- 三行重點：表現最好的門市、最需要處理的門市、最需要處理的事項。
- 一張精簡表格：僅列門市與達成率。
- 結尾一句：完整版報表請見附件 HTML。

## 語氣要求

- 讀者是營運主管，直述、不誇飾，每個結論都要對應具體數字。
- 不使用「表現亮眼」「有待加強」這類沒有數據支撐的形容。
- 若某門市數字異常但原始資料未說明原因，請寫「原因待確認」，不要自行推測。

## 注意事項

- 不要在報告中加入原始資料沒有的數字，也不要為了美觀而捏造趨勢。
- 若原始資料缺少某個欄位，在報告中明確標示「本週未提供」，不要留空或填 0。
