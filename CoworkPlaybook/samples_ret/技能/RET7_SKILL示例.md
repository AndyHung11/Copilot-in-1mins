# 折扣底线检查

按下列顺序判定，顺序不可调换：

1. 读政策。从渠道定价政策取得标准定价、单位成本和毛利底线。
2. 查补贴协议。逐条确认：适用商品、适用渠道、有效期间、每件金额。
   只有范围都对得上，补贴才计入；否则补贴为 0。
3. 算净售价与毛利率。
   净售价 ＝ 标准定价 ×（1 − 折扣率）；
   毛利率 ＝（净售价 − 单位成本 + 补贴）÷ 净售价，分母是净售价。
4. 与底线比较。毛利率大于等于底线为“符合”，否则为“违规”，并写出差距（百分点）。

## 判定标准

- 标准是毛利率，不是折扣深浅。 折扣深不一定违规，折扣浅也不一定合规。
- 补贴只认协议条款，不得把补贴套用到协议未载明的渠道。
- 补贴按每件金额加到毛利，不要换算成折扣率。

## 护栏

- 找不到协议或条款读不出来时，补贴按 0 处理，并在结果中注明。
- 不得自行假设成本、定价或底线；数据缺失要说明缺哪一项。
- 不得省略计算过程，每一笔都要列出净售价、补贴、毛利率。

## 输出格式

用表格列出：编号、渠道、折扣率、净售价、补贴、毛利率、底线、差距、判定。
表格后用一句话说明违规项（如有）及原因。
如用户要求，再把结果填回“折扣例外登记”。
