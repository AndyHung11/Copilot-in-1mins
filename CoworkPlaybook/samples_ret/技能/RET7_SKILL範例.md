# 折扣底線檢查

依下列順序判定，順序不可調換：

1. 讀政策。從通路定價政策取得標準定價、單位成本與毛利底線。
2. 查補貼協議。逐條確認：適用商品、適用通路、有效期間、每件金額。
   只有三者都對得上，補貼才計入；否則補貼為 0。
3. 算淨售價與毛利率。
   淨售價 ＝ 標準定價 ×（1 − 折扣率）；
   毛利率 ＝（淨售價 − 單位成本 + 補貼）÷ 淨售價，分母是淨售價。
4. 與底線比較。毛利率大於等於底線為「符合」，否則為「違規」，並寫出差距（百分點）。

## 判準

- 判準是毛利率，不是折扣深淺。 折扣深不一定違規，折扣淺也不一定合規。
- 補貼只認協議條文，不得把補貼套用到協議未載明的通路。
- 補貼以每件金額加進毛利，不要換算成折扣率。

## 護欄

- 協議找不到或條文讀不出來時，補貼視為 0，並在結果註明。
- 不得自行假設成本、定價或底線；資料缺漏要說明缺哪一項。
- 不得省略計算過程，每筆都要列出淨售價、補貼、毛利率。

## 輸出格式

用表格列出：編號、通路、折扣率、淨售價、補貼、毛利率、底線、差距、判定。
表格後以一句話說明違規者（如有）與原因。
若使用者要求，再把結果填回「折扣例外登錄」。
