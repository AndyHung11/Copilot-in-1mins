# 檔期促銷需求單：2026 秋季「家的溫度」生活節

> 本文件為訓練用虛構範例，品牌、門市、供應商與金額均為占位資料。

## 一、基本資訊

- **檔期名稱**：2026 秋季「家的溫度」生活節
- **檔期期間**：2026/09/18（五）～ 2026/10/15（四），共 28 天
- **提案單位**：商品企劃部
- **參與通路**：全台 8 家門市 + 官方商城 + 電商平台 A／B + 直播通路

## 二、檔期目標

| 指標 | 目標 |
| --- | --- |
| 全通路營收 | 較去年同期 +18% |
| 新增會員數 | +3,000 人 |
| 主打品類客單價 | +12% |
| 檔期整體毛利率 | 不得低於 32% |

## 三、主打品類與策略方向

1. **居家寢飾**：換季主力，主打「入秋換寢具」情境，以組合價提升客單價。
2. **廚房料理**：客單價最高的品類，適合作為滿額贈的門檻拉抬品。
3. **香氛照明**：低單價高頻次，適合作為集客與加購品，帶動連帶率。

## 四、預算

- 行銷推廣費：新台幣 180 萬元（含線上廣告、店頭陳列、DM）
- 贈品成本：新台幣 60 萬元

## 五、需要的交付物（本次一次備齊）

1. **檔期促銷企劃書**（Word）：含檔期主題論述、目標、品類策略、折扣機制、通路分工、時程表、風險與備案。
2. **品項折扣與毛利試算表**（Excel）：逐品項計算建議折扣後售價、折後毛利率、預估銷量與檔期毛利額，並驗證整體毛利率是否守住 32%。
3. **門市執行 SOP**（PDF，單張可張貼於後場）：陳列重點、贈品發放規則、POS 操作注意事項、常見客訴應對。
4. **供應商配合通知信草稿**（Email）：告知檔期期間、需配合的備貨量與到貨期限、贈品供應需求，語氣正式但不強硬。

## 六、限制條件（請務必遵守）

- 檔期整體毛利率**不得低於 32%**，任何折扣建議都要先驗算後再提出。
- 贈品門檻必須是 POS 系統可辨識的單一金額（例如「單筆滿 2,000 元」），不可設計成需人工判斷的條件。
- 庫存低於 300 件的品項不得列為主打品，避免檔期中段斷貨。
- 折扣後售價不得低於成本的 1.25 倍。
