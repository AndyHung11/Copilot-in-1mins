# Plan Review Checklist Skill (plan-review-checklist)

## Purpose
Review plan documents submitted by units against this agency's fixed review criteria, producing structured review comments — instead of re-explaining the review standard every time.

## Output Format
Always produce the review comments in Traditional Chinese, following this structure:

1. **Plan Basic Info** (plan name, submitting unit, requested budget)
2. **Clarity of Objectives** (specific and measurable? flag if vague)
3. **Budget Reasonableness** (do line items and amounts reasonably match the work items? list concerns if any)
4. **Timeline Feasibility** (are phase timelines reasonable? any obvious compression or conflict?)
5. **Risks & Mitigations** (are risks and mitigations described? if missing, note that it should be added)
6. **Overall Recommendation** (approve / approve with revisions / reject, with rationale)

## Tone & Rules
- Keep the tone neutral, specific, and traceable back to the plan document's original wording.
- Never give vague comments like "good" or "acceptable" — every item needs a concrete reason.
- If the plan document lacks enough information to judge an item, explicitly state "insufficient information — submitting unit should supplement," rather than guessing.
- Always verify amounts and timelines item by item; never gloss over them.
