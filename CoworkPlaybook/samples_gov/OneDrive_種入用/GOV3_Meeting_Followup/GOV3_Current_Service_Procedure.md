# Action Acceptance-Evidence Requirements

Before closing any action, it must carry acceptance evidence matching its category. An attachment of the wrong type must not be marked “complete” — list it as “awaiting proof” instead and state what evidence is still missing.

| Category | Required Acceptance Evidence |
|---|---|
| Physical installation | Install-confirmation record (photo or sign-off) |
| System change | Post-change screenshot |
| Coordination / confirmation | Written confirmation |

⚠️ A purchase order or quote proves something was ordered, not that it was completed — it cannot substitute for install-confirmation evidence.
