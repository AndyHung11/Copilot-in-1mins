# Zava Civic Services Agency — Service Routing Guide

This guide applies to every resident and partner request received in the shared service mailbox. Before triage, each request must be matched to a service code so the correct response target can be applied; any request missing a service code, or where the service program cannot be determined, must first receive a reply asking the sender to clarify — never assume the service category from tone or wording alone.

How to compute urgency: remaining time = response target (hours) − hours elapsed. A shorter remaining time means a higher priority — but this is computed against the response target, not the sender's own “urgent” label. A sender's self-flag is informational only and never substitutes for the calculation in this table.

| Service Code | Service Program | Response Target (hours) | Notes |
|---|---|---|---|
| SVC-ACC | Accessibility Accommodation Request | 24 | Statutory deadline, cannot slip |
| SVC-FAC | Facility Maintenance Report | 20 | Internal service commitment |
| SVC-BIL | Billing Inquiry | 48 | Internal service commitment |
| SVC-REC | Public Records Request | 120 | Internal service commitment |
