# 調價原則與競品情報需求

> 本文件為訓練用虛構範例，品牌、品項與數字均為占位資料。

## 一、本次情報蒐集目的

秋季檔期前，需要掌握「同類型生活用品在市場上的公開售價與促銷做法」，作為我方主力品項是否調價的判斷依據。重點不是把競品價格抄下來，而是要能回答：**哪些品項我們明顯偏貴、哪些還有調漲空間、哪些應該用組合而非降價來應對。**

## 二、需要蒐集的外部情報

1. 台灣市場上同類型生活用品（寢飾、鍋具、香氛照明）近三個月的**公開促銷做法**：常見折扣幅度、滿額贈門檻、組合包裝方式。
2. 各主要通路在**秋季換季檔期**慣用的行銷主題與檔期長度。
3. 同類商品的**公開零售價區間**（以可查證的公開資訊為準，需附來源連結）。
4. 消費者近期在生活用品類別的**討論重點**（例如環保材質、收納、送禮需求）。

## 三、調價原則（紅線，不可違反）

| 編號 | 原則 |
| --- | --- |
| R-01 | 調價後毛利率**不得低於 38%**。低於此線者一律不調降售價，改以組合或贈品因應。 |
| R-02 | 單次調降幅度不得超過原售價的 **15%**，避免傷害品牌價格帶認知。 |
| R-03 | 近四週銷量低於 100 件的品項，**不以降價作為第一手段**，應先檢討陳列與曝光。 |
| R-04 | 毛利率高於 55% 且銷量前三名的品項，可評估**小幅調漲**（3%～5%）。 |
| R-05 | 任何調價建議都必須同時列出調整後的毛利率與預估毛利額變化，不得只寫「建議降價」。 |

## 四、交付格式

在原始的主力品項清單上，新增以下欄位並輸出成 Excel：

- 競品參考價區間（附來源）
- 我方價格相對位置（偏高／持平／偏低）
- 建議動作（調降／維持／調漲／改用組合）
- 建議調整後售價
- 調整後毛利率
- 建議理由（一句話，需對應到上表的原則編號）

最後加上一段「整體建議摘要」，說明本次共建議調整幾個品項、預估對整體毛利率的影響，以及哪些品項屬於「不建議動價、改用其他手段」。

## 五、引用要求

外部情報必須附上可點擊的來源連結；若某項資訊查不到可靠公開來源，請直接註明「查無可靠公開來源」，**不要以推估數字填補**。
