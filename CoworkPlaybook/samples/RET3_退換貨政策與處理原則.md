# 退換貨政策與客訴處理原則（客服內部版）

> 本文件為訓練用虛構範例，條款內容為教學用途撰寫，非真實法律文件。

## 一、退換貨政策條文

| 編號 | 條文 |
| --- | --- |
| P-01 | **網路通路**（官方商城／電商平台／直播）：自商品送達次日起七日內為鑑賞期，可無條件申請退貨，商品須保持完整包裝與配件。 |
| P-02 | **實體門市**：非瑕疵之退貨以「換貨或等值商品」為原則，須於購買日起七日內、憑發票與完整包裝辦理。 |
| P-03 | **商品瑕疵**（不分通路）：自送達或購買日起十四日內，經確認為出廠瑕疵者，可選擇退貨全額退款或換貨，**退貨運費由公司負擔**。 |
| P-04 | **到貨逾期**：若逾網頁公告到貨時程滿三個工作天仍未出貨，客戶可要求取消訂單並全額退款，不受鑑賞期限制。 |
| P-05 | 貼身衣物、食品、已拆封之個人衛生用品不適用鑑賞期，商品瑕疵除外。 |
| P-06 | 退款作業時程：確認退貨收件後三至五個工作天內完成退款，信用卡退刷依發卡行作業時間。 |

## 二、案件分級與處理時效

| 等級 | 判定條件 | 首次回覆時效 | 處理權限 |
| --- | --- | --- | --- |
| A（高） | 商品瑕疵且有安全疑慮、客戶明確表達要申訴或上網公開、逾期未回覆超過 48 小時 | 4 小時內 | 需客服主管覆核 |
| B（中） | 一般瑕疵退換貨、到貨逾期、金額爭議 | 1 個工作天內 | 客服專員可處理 |
| C（低） | 商品問題諮詢、政策說明、無爭議之一般退換貨 | 2 個工作天內 | 客服專員可處理 |

## 三、回覆撰寫原則

1. **先致歉、再說明、最後給明確下一步**，三段結構固定，不可只丟政策條文。
2. **明確引用適用條款編號**（例如 P-03），讓客戶知道判斷依據，也方便內部覆核。
3. **不承諾政策以外的補償**。若客戶要求超出政策範圍（例如額外賠償），一律標記為需主管裁量，不可自行答應。
4. **不推卸責任**，不使用「這是物流的問題」「系統就是這樣」等說法。
5. 每封回覆都要具體寫出：適用條款、公司將採取的動作、客戶需要配合的動作、預計完成時間。
6. 若客戶已明顯表達不滿或提及公開申訴，於信末加註「本案已升級由客服主管跟進」。

## 四、必要時的內部通知

- A 級案件：同時通知客服主管與該通路負責人。
- 涉及門市之案件：通知該門市店長，並附上處理結論，避免門市與客服說法不一致。
- 同一品號 30 天內出現 3 件以上瑕疵客訴：通知商品企劃與品保，評估是否整批下架。
