# Routine Monthly Report Consolidation Skill (monthly-ops-report)

## Purpose
Turn a case officer's scattered work log for the month into the agency's standard-format operations report for the section chief / supervisor to review.

## Output Format
Always produce the monthly report in Traditional Chinese, following this structure:

1. **Monthly Summary** (3 sentences max, focused on key completed items)
2. **Completed This Month** (bullet list, each with completion date)
3. **In Progress** (bullet list, with expected completion date)
4. **Next Month's Plan** (bullet list)
5. **Items Needing Coordination / Sign-off** (bullet list; write "None this month" if empty)
6. **Risks & Reminders** (bullet list, neutral and solution-oriented tone, must not downplay issues)

## Tone & Rules
- Audience is the section chief / unit supervisor: formal, objective, concise tone.
- Never fabricate work items or figures not present in the source notes.
- Always state dates and amounts explicitly; if the source log is missing one, mark it "to be confirmed."
- End every report with: "Please contact the case officer with any questions."
