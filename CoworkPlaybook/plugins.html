先搞懂：外掛程式跟技能差在哪先搞懂：插件跟技能差在哪First: plugin vs. skill

在 Cowork 裡，技能（skill）是一份 SKILL.md，用自然語言寫清楚「什麼時候該做、照什麼步驟做、產出長什麼樣」；外掛程式（plugin）則是把一組技能（可再加上連接外部系統的 connector）打包成一個 .zip 套件，方便一次安裝、一次分享、一次治理。這四包都是 skill-only：只有技能、沒有連接器，所以裝上就能用，不必授權任何外部服務。在 Cowork 里，技能是一份 SKILL.md，用自然语言写清楚“什么时候该做、按什么步骤做、产出长什么样”；插件则是把一组技能（可再加上连接外部系统的 connector）打包成一个 .zip 包，方便一次安装、一次分享、一次治理。这四包都是 skill-only：只有技能、没有连接器，所以装上就能用，不必授权任何外部服务。In Cowork a skill is a SKILL.md file that says, in plain language, when to act, what steps to follow and what the output should look like. A plugin bundles a set of skills (optionally plus connectors to external systems) into one .zip package so it can be installed, shared and governed as a unit.
