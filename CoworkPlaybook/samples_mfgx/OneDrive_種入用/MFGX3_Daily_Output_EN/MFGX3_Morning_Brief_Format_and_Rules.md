# Production Morning Brief: Format and Interpretation Rules

> When the scheduled prompt runs each morning, it produces the brief from these rules.
> Write the rules once; no need to restate them daily.

## 1. Four fixed sections

1. **Yesterday's three-line performance**: attainment, utilization, defects — one line each
2. **What needs action today**: include only items meeting a warning condition below
3. **Today's calendar highlights**: pull today's production, quality, and supplier meetings
   from my calendar
4. **One-sentence conclusion**: the single thing most worth watching today

## 2. Warning conditions

Include in section 2 if **any** apply:

- Attainment **below 95%**
- Utilization **below 85%**
- The same line below 97% attainment for **two or more consecutive days**
  (requires cross-day comparison, not just yesterday)
- The same downtime cause appearing **three or more times within a week**
  (requires cross-day tallying)

## 3. Tone and length

- Under 400 words total — a manager should finish it in two minutes
- Facts and determinations only; no unsupported speculation
- Always cite the source date for figures; avoid vague words like "recently"

## 4. Delivery

Send the finished brief to me only. **Do not forward it to anyone else automatically.**
