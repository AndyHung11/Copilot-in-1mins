# 工程样品放行判定原则

**文件编号**：QP-QA-019　**版次**：Rev.E　**生效日**：2026-04-15

## 判定顺序

按下列五条逐项检查，任一条不成立即不得放行。

### 第一条　qual 状态为“已通过”

按一般出货流程放行，无需额外限制。

### 第二条　qual 状态为“进行中”

仅限以工程样品名义出货，并同时符合：

- **单次数量上限 50 颗**，超量者须拆单或减量。
- 外箱**与**单颗包装均须标识：

  ```
  ENGINEERING SAMPLE — NOT FOR PRODUCTION
  ```

  仅外箱标识、未标识单颗包装者，视为标识不完整。

### 第三条　有规格偏离者

须**同时**满足下列两个条件，**缺一不可放行**：

1. 已取得客户**书面同意**；
2. 该笔偏离**仍在有效期内**。

⚠️ 客户曾经同意，不代表偏离现在仍然有效。
两者为各自独立之条件，须分别查证。

### 第四条　偏离已逾期

须先向客户申请展期并取得回签，方得放行。
展期期间不得以“客户先前已同意”为由先行出货。

### 第五条　NPI 首批样品

除上述各条外，另须附**首件检验报告（FAI）**。
无 FAI 者不得放行，不因客户催料而例外。

## 判定结果分类

| 结果 | 含义 |
|---|---|
| 可放行 | 全部条件成立 |
| 不可放行 | 有条件不成立，且无法于出货前补正 |
| 有条件放行 | 条件可于出货前补正（减量、补标识、补附报告） |

## 记录

每笔判定须记录判定人、判定日期与所依据之条文，保存三年。
