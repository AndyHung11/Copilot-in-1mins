# ISO 9001 Pre-Audit Inventory Checklist

> This is what must be inventoried before the audit. Cowork scans every document in the
> materials folder itself and checks it against this table — nobody needs to build the
> list first.

## 1. Four categories to inventory

### 1. Station SOP document control
- Each station must have **exactly one** current effective version
- Document number, version, effective date, next review date, and owner — **all five present**
- The **next review date must not be earlier than today** (expired = non-conforming)
- Draft versions must not coexist with the current version in the active document area

### 2. Certificate validity
- Certificates **must still be valid on the audit date**
- Anything **within 60 days** of expiry is flagged "expiring soon" and renewal must start early

### 3. Measurement equipment calibration
- Each instrument's **next calibration date must not be earlier than today**
- Anything **within 30 days** of the next calibration date is flagged "expiring soon"

### 4. File naming and filing
- File names must contain the **document number and version**
- Names like "latest", "new version", or "(2026)" that carry no version information are not allowed

## 2. What to do after the inventory

1. Create an audit folder and file the **conforming** documents under three subcategories:
   **SOPs / Certificates / Calibration records**
2. Produce a gap list stating, for each item: document name, which rule it violates, the
   owner, and a suggested deadline
3. **Group the gaps by owner** and email each person only their own items
   — do not send the entire gap list to everyone

> ⚠️ All email is drafted first and sent only after approval.
