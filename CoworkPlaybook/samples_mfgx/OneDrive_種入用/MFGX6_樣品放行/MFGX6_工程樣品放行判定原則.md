# 工程樣品放行判定原則

**文件編號**：QP-QA-019　**版次**：Rev.E　**生效日**：2026-04-15

## 判定順序

依下列五條逐項檢查，任一條不成立即不得放行。

### 第一條　qual 狀態為「已通過」

依一般出貨流程放行，無需額外限制。

### 第二條　qual 狀態為「進行中」

僅限以工程樣品名義出貨，並同時符合：

- **單次數量上限 50 顆**，超量者須拆單或減量。
- 外箱**與**單顆包裝均須標示：

  ```
  ENGINEERING SAMPLE — NOT FOR PRODUCTION
  ```

  僅外箱標示、未標示單顆包裝者，視為標示不完整。

### 第三條　有規格偏離者

須**同時**滿足下列兩個條件，**缺一不可放行**：

1. 已取得客戶**書面同意**；
2. 該筆偏離**仍在有效期內**。

⚠️ 客戶曾經同意，不代表偏離現在仍然有效。
兩者為各自獨立之條件，須分別查證。

### 第四條　偏離已逾期

須先向客戶申請展延並取得回簽，方得放行。
展延期間不得以「客戶先前已同意」為由先行出貨。

### 第五條　NPI 首批樣品

除上述各條外，另須附**首件檢驗報告（FAI）**。
無 FAI 者不得放行，不因客戶催料而例外。

## 判定結果分類

| 結果 | 意義 |
|---|---|
| 可放行 | 全部條件成立 |
| 不可放行 | 有條件不成立，且無法於出貨前補正 |
| 有條件放行 | 條件可於出貨前補正（減量、補標示、補附報告） |

## 紀錄

每筆判定須記錄判定人、判定日期與所依據之條文，保存三年。
